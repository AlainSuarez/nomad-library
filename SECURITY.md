# Security

Please report security problems privately: [open a private advisory](https://github.com/Chrisgpresents/nomad-library/security/advisories/new). Don't open a public issue, and don't test against other people's accounts or data.

Useful details: what you found, the steps to reproduce it, and what someone could do with it. You'll get a reply on the advisory, and you're credited in [CREDITS.md](CREDITS.md) once it's fixed, unless you'd rather not be.

Testing the live site is fine as long as it's gentle: no load testing, no automated scanning that floods the site or the libraries behind it, and nothing that touches accounts that aren't yours.

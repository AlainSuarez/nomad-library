# The Nomad Library name and logo

The code in this repository is open source under the [GNU AGPL v3](LICENSE). The name **Nomad Library**, the **Nomad Over Normal** name, and the disc and library card logo (the files in `brand/` and `public/icons/`) are not. They belong to Nomad Over Normal.

You're welcome to fork the code and run your own version. If you do, please:

- give it a different name and logo,
- don't present it as the official Nomad Library or as made by Nomad Over Normal,
- run it on your own domain.

Saying "based on Nomad Library" with a link back is fine and appreciated.

The official site is https://library.nomadovernormal.com.
